# Автофагия – дыхательная практика (7 мин)

Это веб‑приложение реализует интерактивную 7‑минутную дыхательную практику «Дыхание аутофагии». Пользователь нажимает **Старт**, следит за таймерами и визуальными индикаторами (цикл вдох‑задержка‑выдох, фазовые блоки) и может включать/выключать звук.

## Как запустить

- Откройте `index.html` в браузере (дважды‑клик или `open index.html`).
- Нажмите **Старт**, используйте кнопки **Пауза**/**Продолжить** и **Сброс**.
- При желании разместите файл на GitHub Pages, как в предыдущем проекте.

## Технологии

- HTML5 + CSS (чистый стиль, без фреймворков)
- Чистый JavaScript (ES6) для таймеров, звуков и SVG‑индикаторов
- Нет внешних зависимостей, всё работает офлайн.

Если хотите добавить собственный дизайн, графику или улучшить звук – замените стили/изображения, всё в одном файле.
